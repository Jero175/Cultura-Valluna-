# Cultura Valluna

Sitio web responsive sobre la cultura del Valle del Cauca.

## Publicar en GitHub Pages
1. Sube todos los archivos conservando las carpetas.
2. En GitHub entra a Settings > Pages.
3. Selecciona Deploy from a branch.
4. Elige `main` y `/root`.
5. Guarda y espera la publicación.

Las imágenes y el mapa pueden requerir conexión a Internet.
